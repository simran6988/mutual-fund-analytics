# Mutual Fund Analytics

## Project Overview

Mutual Fund Analytics is a data analytics project that focuses on analyzing mutual fund datasets to generate meaningful insights using Python, SQL, SQLite, and data visualization tools.

## Objectives

- Clean and preprocess mutual fund datasets.
- Store and manage data using SQLite.
- Perform exploratory data analysis (EDA).
- Generate business insights from the data.
- Build interactive dashboards.
- Present findings through reports and visualizations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Matplotlib
- VS Code
- Git & GitHub
